---
title: "Feature Flags"
description: "Optional integrations included in the official binary and Docker image, and how to enable each at runtime."
---

Some integrations are bundled as **optional features**. Whether each integration is available depends on which build of Nexus you run; whether it is *active* is then controlled by configuration.

This page lists the optional features, what is included in the official distributions, and how to turn each one on at runtime.

---

## What ships in the official distributions

| Distribution | Always included | Optional features compiled in |
|--------------|----------------|-------------------------------|
| Official Docker image (`ghcr.io/draskencloud/nexus:<tag>`) | SQLite storage | PostgreSQL storage, OpenTelemetry trace export |
| Official Linux / macOS binaries (GitHub Releases) | SQLite storage | PostgreSQL storage, OpenTelemetry trace export |

For most production deployments, the official image covers the common cases (SQLite for single-instance, PostgreSQL for multi-replica, OTLP for tracing).

If you need a feature that is **not** compiled into the official image — MySQL/MariaDB, CockroachDB, or Memcached — you have two options:

1. Run a community-published image that includes the feature, or
2. Build a custom image. See the [Nexus repository on GitHub](https://github.com/draskencloud/nexus) for build instructions.

---

## Available features

| Feature | Use case | Available in official image |
|---------|----------|-----------------------------|
| **SQLite storage** | Single-instance deployments, dev environments | Yes (always) |
| **PostgreSQL storage** | Multi-instance / horizontally scaled deployments | Yes |
| **OpenTelemetry (OTLP)** | Distributed tracing export | Yes |
| **MySQL / MariaDB storage** | When your operations team standardizes on MySQL | Custom build |
| **CockroachDB storage** | Geo-distributed deployments needing CockroachDB | Custom build |
| **Memcached cache** | Memcached as the cache backend instead of Redis | Custom build |

## Enabling each feature at runtime

### SQLite (default)

Used unless you configure another driver. Suitable for dev and single-instance production:

```bash
export GATEWAY_DATABASE__DRIVER=sqlite
export GATEWAY_DATABASE__URL="sqlite:./data/gateway.db?mode=rwc"
```

<Note>
SQLite cannot be shared across replicas — use PostgreSQL for multi-instance deployments.
</Note>

### PostgreSQL

```bash
export GATEWAY_DATABASE__DRIVER=postgres
export GATEWAY_DATABASE__URL="postgres://user:password@host:5432/gateway"
```

### OpenTelemetry trace export

Compiled in to the official image, but dormant unless an endpoint is set:

```bash
export GATEWAY_OTLP_ENDPOINT=http://otel-collector:4318
```

If `GATEWAY_OTLP_ENDPOINT` is unset, no traces are exported and there is no performance impact.

See [Distributed Tracing](/nexus/observability/distributed-tracing) for full setup.

### MySQL / MariaDB (custom build only)

```bash
export GATEWAY_DATABASE__DRIVER=mysql
export GATEWAY_DATABASE__URL="mysql://user:password@host:3306/gateway"
```

### CockroachDB (custom build only)

CockroachDB uses the PostgreSQL wire protocol with compatibility shims:

```bash
export GATEWAY_DATABASE__DRIVER=cockroach
export GATEWAY_DATABASE__URL="postgres://user:password@host:26257/gateway?sslmode=verify-full"
```

### Memcached cache (custom build only)

```bash
export GATEWAY_CACHE__BACKEND=memcached
export GATEWAY_CACHE__MEMCACHED__URL=memcached://localhost:11211
```

## What happens if a feature is missing

If a runtime configuration asks for a feature that is not bundled into the running build:

| Situation | Behaviour |
|-----------|-----------|
| `GATEWAY_DATABASE__DRIVER=postgres` but PostgreSQL not bundled | Startup fails with a clear "driver not available" error |
| `GATEWAY_CACHE__BACKEND=memcached` but Memcached not bundled | Startup fails with a clear "backend not available" error |
| `GATEWAY_OTLP_ENDPOINT` set but OTLP not bundled | Variable is ignored; no traces exported |
| `GATEWAY_DATABASE__DRIVER=sqlite` (always available) | Always works |

When startup fails, the error message names the missing feature so you can switch to a build that includes it.
