## Health Check

<ParamField query="GET /api/v1/health" />

No authentication required.

```bash
curl http://localhost:9090/api/v1/health
```

```json
{
  "status": 200,
  "message": "success",
  "data": {
    "db": "ok",
    "db_driver": "sqlite",
    "uptime_secs": 3600
  }
}
```

## Get Config

<ParamField query="GET /api/v1/config" />

```bash
curl http://localhost:9090/api/v1/config \
  -H "Authorization: Bearer YOUR_ADMIN_TOKEN"
```

Returns the current runtime configuration.

---

## Patch Config

<ParamField query="PATCH /api/v1/config" />

Hot-reload selected runtime tunables without restart:

```bash
curl -X PATCH http://localhost:9090/api/v1/config \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_ADMIN_TOKEN" \
  -d '{
    "rate_limit_requests": 2000,
    "rate_limit_window_secs": 60
  }'
```

<Note>
  Static settings (ports, TLS paths, DB driver) cannot be patched and require a restart.
</Note>

## Reload Config
