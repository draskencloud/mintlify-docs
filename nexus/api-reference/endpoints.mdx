## Create Endpoint

<ParamField query="POST /api/v1/apps/:app_id/versions/:version_id/revisions/:revision_id/endpoints" />

```bash
curl -X POST .../endpoints \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_ADMIN_TOKEN" \
  -d '{
    "method": "GET",
    "path": "/orders",
    "backend_path": "/v2/orders",
    "policy_override": {
      "rate_limit": {"enabled": true, "requests": 100, "window_seconds": 60}
    }
  }'
```

**Body Parameters**

| Field | Required | Description |
|-------|----------|-------------|
| `method` | Yes | HTTP method or `*` for any |
| `path` | Yes | Path relative to the version's gateway_path |
| `backend_path` | No | Override upstream path. Defaults to `path` |
| `policy_override` | No | Endpoint-level policy overrides |
