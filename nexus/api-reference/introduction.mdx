The management API runs on port `9090` and is used to configure apps, tokens, endpoints, and runtime settings.

## Base URL

Each operation page on this reference has a **server selector** at the top of the request panel. Pick one of the presets or choose **Custom** to enter your own host:

| Server | When to use |
|--------|-------------|
| `http://localhost:9090` | Local development; or via `kubectl port-forward svc/nexus 9090:9090` |
| `{scheme}://{host}` (Custom) | Any other deployment — set `scheme` (`http` / `https`) and `host` (e.g. `nexus.internal.acme.com`) |

The selected server is used for all **Try It** requests on that page. Your selection persists across pages within the session.

<Note>
The management API runs on port `9090` and should never be exposed to the public internet. Reach it through a VPN, jump host, internal load balancer, or `kubectl port-forward`.
</Note>

## Authentication

When `GATEWAY_SERVER__ADMIN_TOKEN` is set, all management API requests require:

```
Authorization: Bearer YOUR_ADMIN_TOKEN
```

## Interactive Docs

Enable Swagger UI by setting `GATEWAY_SERVER__SWAGGER_ENABLED=true`, then open:

```
http://localhost:9090/swagger-ui/
```

## Key Endpoints

| Method | Path | Description |
|--------|------|-------------|
| `GET` | `/api/v1/health` | Health check |
| `GET` | `/api/v1/version` | Version and build info |
| `GET` | `/api/v1/apps` | List all apps |
| `POST` | `/api/v1/apps` | Create an app |
| `PATCH` | `/api/v1/apps/{id}` | Update an app |
| `DELETE` | `/api/v1/apps/{id}` | Delete an app |
| `POST` | `/api/v1/apps/{id}/versions` | Create a version (optionally auto-creates rev-1) |
| `GET` | `/api/v1/apps/{id}/versions` | List versions |
| `PATCH` | `/api/v1/apps/{id}/versions/{vid}` | Update a version |
| `DELETE` | `/api/v1/apps/{id}/versions/{vid}` | Delete a version |
| `POST` | `/api/v1/apps/{id}/versions/{vid}/revisions` | Create a revision |
| `GET` | `/api/v1/apps/{id}/versions/{vid}/revisions` | List revisions |
| `POST` | `/api/v1/apps/{id}/versions/{vid}/revisions/{rid}/activate` | Activate a revision |
| `GET` | `/api/v1/apps/{id}/versions/{vid}/endpoints` | List endpoints (current revision) |
| `POST` | `/api/v1/apps/{id}/versions/{vid}/endpoints` | Create endpoint (current revision) |
| `PATCH` | `/api/v1/apps/{id}/versions/{vid}/endpoints/{eid}` | Update an endpoint |
| `DELETE` | `/api/v1/apps/{id}/versions/{vid}/endpoints/{eid}` | Delete an endpoint |
| `GET` | `/api/v1/apps/{id}/tokens` | List API tokens |
| `POST` | `/api/v1/apps/{id}/tokens` | Issue an API token |
| `DELETE` | `/api/v1/apps/{id}/tokens/{tid}` | Revoke a token |
| `GET` | `/api/v1/metrics` | Prometheus metrics |
| `GET` | `/api/v1/config` | Get runtime config |
| `POST` | `/api/v1/config/reload` | Reload config (Pro tier) |
