## List Tokens

```bash
curl http://localhost:9090/api/v1/apps/payments/tokens \
  -H "Authorization: Bearer YOUR_ADMIN_TOKEN"
```

## Issue Token

<ParamField query="POST /api/v1/apps/:app_id/tokens" />

```bash
curl -X POST http://localhost:9090/api/v1/apps/payments/tokens \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_ADMIN_TOKEN" \
  -d '{
    "name": "Mobile App",
    "scopes": ["read", "write"],
    "expires_at": "2027-01-01T00:00:00Z",
    "metadata": {
      "tenant_id": "acme",
      "plan": "pro"
    }
  }'
```

**Body Parameters**

| Field | Required | Type | Description |
|-------|----------|------|-------------|
| `name` | Yes | string | Token label |
| `scopes` | Yes | string[] | Permission scopes |
| `expires_at` | No | datetime | Expiry (ISO 8601). Never expires if omitted |
| `metadata` | No | object | Key-value pairs forwarded as request headers to the backend |

**Response** — the `raw_value` is returned only once:

```json
{
  "status": 200,
  "data": {
    "token": {
      "id": "uuid",
      "name": "Mobile App",
      "scopes": ["read", "write"],
      "expires_at": null,
      "created_at": "2026-05-09T00:00:00Z"
    },
    "raw_value": "gw_live_xxxxxxxxxxxxxxxxxxxx"
  }
}
```

## Update Token

<ParamField query="PATCH /api/v1/apps/:app_id/tokens/:token_id" />

```bash
curl -X PATCH http://localhost:9090/api/v1/apps/payments/tokens/{id} \
  -d '{"scopes": ["read"]}'
```

---

## Rotate Token

<ParamField query="POST /api/v1/apps/:app_id/tokens/:token_id/rotate" />

Issues a new token value. The old value is immediately invalidated.

```bash
curl -X POST http://localhost:9090/api/v1/apps/payments/tokens/{id}/rotate \
  -H "Authorization: Bearer YOUR_ADMIN_TOKEN"
```

---

## Revoke Token

<ParamField query="DELETE /api/v1/apps/:app_id/tokens/:token_id" />

```bash
curl -X DELETE http://localhost:9090/api/v1/apps/payments/tokens/{id} \
  -H "Authorization: Bearer YOUR_ADMIN_TOKEN"
```
