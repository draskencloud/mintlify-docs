This guide covers running the Nexus API Gateway by Drasken Cloud directly on a host, without containers.

## Prerequisites

| Requirement | Notes |
|---|---|
| Linux or macOS host (x86_64 or arm64) | Pre-built binaries are available for these architectures |
| Redis (optional) | Required only for multi-replica deployments. Single-instance setups can use the in-process cache |

## Getting the binary

Download the latest release for your platform from [GitHub Releases](https://github.com/draskencloud/nexus/releases). Each release ships pre-built binaries:

```bash
# Linux x86_64
curl -L -o nexus https://github.com/draskencloud/nexus/releases/latest/download/nexus-linux-x86_64
chmod +x nexus

# Linux arm64
curl -L -o nexus https://github.com/draskencloud/nexus/releases/latest/download/nexus-linux-arm64
chmod +x nexus

# macOS arm64
curl -L -o nexus https://github.com/draskencloud/nexus/releases/latest/download/nexus-darwin-arm64
chmod +x nexus
```

Move the binary into `/usr/local/bin/` (or anywhere on your `PATH`) and you are ready to run.

The official binaries include SQLite and PostgreSQL storage drivers and OpenTelemetry trace export. If you need a feature that is not bundled (MySQL, CockroachDB, or Memcached), see [Feature Flags](/nexus/configuration/feature-flags) for the build-from-source path on the public repository.

## Configuration

### Config File

The gateway auto-loads `config/default.toml` relative to the working directory at startup. A full annotated example ships with the repository. Key sections:

```toml
[server]
proxy_port = 8080
mgmt_port  = 9090
admin_token = "change-me"
log_level  = "info"
log_format = "text"

db_driver    = "sqlite"
database_url = "sqlite://gateway.db?mode=rwc"
auto_migrate = true
```

See the [Configuration Overview](/nexus/configuration/overview) and [Server Reference](/nexus/configuration/server) for all available keys.

### .env File

The gateway calls `dotenvy` at startup and loads a `.env` file from the current working directory if one exists. This is a convenience for local development:

```bash
# .env
GATEWAY_SERVER__ADMIN_TOKEN=dev-token
GATEWAY_DATABASE_URL=sqlite://./dev.db?mode=rwc
RUST_LOG=nexus=debug
```

Actual environment variables in the shell always override `.env` values.

### Environment Variable Override

Every config key can be set via environment variable using the `GATEWAY_` prefix and `__` for nesting:

```bash
export GATEWAY_SERVER__LOG_FORMAT=json
export GATEWAY_SERVER__PROXY_TIMEOUT_MS=60000
export GATEWAY_DATABASE_URL="postgres://user:pass@localhost/gateway"
```

## Running

```bash
./target/release/nexus
```

Or from the project root (which auto-resolves `config/default.toml`):

```bash
cargo run --release
```

The process logs to stdout. On startup you should see lines like:

```
INFO  nexus: proxy listening on 0.0.0.0:8080
INFO  nexus: management API listening on 0.0.0.0:9090
```

Verify the service is healthy:

```bash
curl http://localhost:9090/api/v1/health
```

## Log Output

Logs go to **stdout** by default. To redirect to a file while also keeping them in the terminal:

```bash
./target/release/nexus 2>&1 | tee gateway.log
```

For structured JSON logs (recommended for log shippers like Filebeat, Fluentd, or Vector):

```bash
GATEWAY_SERVER__LOG_FORMAT=json ./target/release/nexus 2>&1 | tee gateway.log
```

To increase verbosity:

```bash
RUST_LOG=nexus=debug ./target/release/nexus
```

`RUST_LOG` accepts standard `tracing` filter directives and takes precedence over `log_level` in the config file.

## Signal Handling

| Signal | Behaviour |
|---|---|
| `SIGTERM` | Graceful shutdown (drains in-flight requests up to `shutdown_timeout_secs`) |
| `SIGINT` (Ctrl-C) | Same as `SIGTERM` |
| `SIGHUP` | No effect (config reload is via the management API: `POST /api/v1/config/reload`) |

See [Graceful Shutdown](/nexus/deployment/graceful-shutdown) for the full shutdown sequence.

## Systemd Service Unit

Create `/etc/systemd/system/gateway.service`:

```ini
[Unit]
Description=Nexus API Gateway by Drasken Cloud
Documentation=https://docs.draskencloud.io/gateway
After=network-online.target
Wants=network-online.target
# Add these lines if using Postgres/Redis:
# After=postgresql.service redis.service
# Requires=postgresql.service

[Service]
Type=exec
User=gateway
Group=gateway
WorkingDirectory=/opt/gateway
ExecStart=/opt/gateway/bin/nexus
Restart=on-failure
RestartSec=5s

# Load secrets from an environment file (not checked into version control)
EnvironmentFile=-/opt/gateway/gateway.env

# Standard output → journald
StandardOutput=journal
StandardError=journal
SyslogIdentifier=gateway

# Graceful shutdown: send SIGTERM and wait up to 35s (matches shutdown_timeout_secs + buffer)
KillMode=process
KillSignal=SIGTERM
TimeoutStopSec=35

# Hardening
NoNewPrivileges=yes
ProtectSystem=strict
ReadWritePaths=/opt/gateway/data /opt/gateway/logs
PrivateTmp=yes

[Install]
WantedBy=multi-user.target
```

Set up the service:

```bash
# Create service user
sudo useradd -r -s /sbin/nologin -d /opt/gateway gateway

# Copy binary and config
sudo mkdir -p /opt/gateway/{bin,data,logs,config/apps}
sudo cp target/release/nexus /opt/gateway/bin/
sudo cp config/default.toml /opt/gateway/config/

# Create secrets file (readable only by root / systemd)
sudo tee /opt/gateway/gateway.env > /dev/null <<'EOF'
GATEWAY_SERVER__ADMIN_TOKEN=your-secure-token
GATEWAY_DATABASE_URL=sqlite:///opt/gateway/data/gateway.db
EOF
sudo chmod 600 /opt/gateway/gateway.env

# Set ownership
sudo chown -R gateway:gateway /opt/gateway

# Enable and start
sudo systemctl daemon-reload
sudo systemctl enable --now gateway
```

View logs:

```bash
journalctl -u gateway -f
```

## Upgrading

1. Download the new binary from [GitHub Releases](https://github.com/draskencloud/nexus/releases) and place it next to the running one: `sudo cp nexus /opt/gateway/bin/nexus.new`
2. Atomically replace and restart:
   ```bash
   sudo mv /opt/gateway/bin/nexus.new /opt/gateway/bin/nexus
   sudo systemctl restart gateway
   ```

For zero-downtime upgrades on a single host, use a load balancer and perform a rolling restart — see [Horizontal Scaling](/nexus/deployment/horizontal-scaling).
